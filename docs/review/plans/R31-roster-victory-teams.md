# R31 — Победа и стартовый ростер: убрать зашитый 1v1

**Severity:** High (gameplay correctness для >2 игроков) / Medium для текущего MVP · **Домен:** gameplay / integration · **Roadmap:** P1

**Статус валидации:** ✅ Подтверждено по коду

## Проблема
Условие победы считает выживших **игроков**, а не **команды**: при команде из нескольких игроков победа сработает преждевременно (пока в живых один игрок «своей» стороны) или не сработает корректно при союзниках. Дополнительно старт партии зашит под двух игроков (`PlayerId(1)`/`PlayerId(2)`), а рендер использует фиксированную посадку (seat), а не инъекцию из ростера. Итог: движок фактически поддерживает только 1v1, хотя остальная архитектура претендует на общий multiplayer.

## Где в коде
- `src/SteelConveyorWar.Core/Systems/VictorySystem.cs:16-35` — `CheckVictory`: `activePlayers.Count == 1` считает игроков, а не команды/стороны.
- `src/SteelConveyorWar.Core/GameSimulation.cs:1393-1416` — старт партии зашит на `PlayerId(1)` / `PlayerId(2)` (фиксированный ростер из двух).
- `src/SteelConveyorWar.Sfml/Rendering/WorldRenderer.cs:217-250,417-422` — рендер опирается на фиксированный seat, а не на инъектированную посадку из ростера.

## План фикса
1. Ввести понятие team/side (или alliance) в состояние игрока; условие победы формулировать через «осталась одна активная команда», а не «остался один активный игрок».
2. Стартовый ростер задавать данными: список сидов (seat) с назначением player→team, стартовыми позициями и цветами; убрать хардкод `PlayerId(1)/(2)`.
3. Рендер получает посадку/цвета через инъекцию из ростера, а не через фиксированный seat.
4. Для текущего MVP сохранить 1v1 как частный случай ростера (две команды по одному игроку), но без зашитых допущений в коде.

## Тесты
- Тест победы: команда 2v2 — победа объявляется только когда все игроки одной стороны выбыли, а не при первом выбывшем.
- Тест старта: ростер из N сидов создаёт N корректно назначенных игроков/команд без хардкода.
- Тест рендера: цвета/позиции берутся из ростера (смена ростера меняет отрисовку без правки кода).

## Definition of Done
- Победа определяется по командам, а не по числу игроков.
- Стартовый состав и посадка — data-driven (ростер), без зашитого 1v1.
